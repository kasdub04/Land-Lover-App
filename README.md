# Communic8

## Description

An educational step tracking app that acts as a tour guide, when you've reached a step milestone, you will be rewarded with a ‘message in a bottle’ containing a fun fact about pirates. The message is then saved in your ‘captain's log’ for you to refer to. You can add friends and compare how many facts you’ve discovered or the distance you've walked overtime.

## Features

 * Homepage:
    * Has users icon, and name displayed
    * Minimap of their current location
    * Step tracker and button to update the tracker

 * Map Page:
    * Large-scale map of the user's current location and nearby treasures

 * Captains Log:
    * Collection of the treasures and information the user collects over time.
    * Each entry has an image and information about a topic in pirate history.

 * Crew:
    * A list of your and your friends' profiles
    * How many treasures they've found (the information in the captain's log)  
    * Displayed how long they've had the app
    * How far they've travelled today

 * Settings:
    * The first tab has character/user customisation
      * change name
      * change icon
      * change icon colour
    * The second tab is settings, which includes permissions, display options and account settings.
